# Portfolio — Ranjeet Kumar Raj

My personal portfolio website, built with React.js.

## Live Site

https://ranjeetraj.github.io

## Author

- [Ranjeet Kumar Raj](https://github.com/RanjeetRaj444)

## Tech Stack

**Frontend:** React.js, HTML, CSS, JavaScript, styled-components
**Libraries:** framer-motion, AOS, react-scroll, react-elastic-carousel, react-icons
**Tools:** VS Code, Git, GitHub

## Getting Started

```bash
npm install
npm start      # run locally at http://localhost:3000
npm run build  # production build
npm run deploy # deploy to GitHub Pages
```
